10. Safety Control System & Electrical Driver Verification

Software state machine, watchdog configuration, and mandatory motor driver verification checklist.

Mandatory Hardwired Emergency-Stop Requirement

WARNING: A software STOP ALL button is NOT a substitute for a physical emergency-stop switch.

Before testing under power, wire a physical mushroom-head NC (Normally Closed) Emergency Stop switch in series with the positive 12V supply feeding all wheel and linear actuator motor drivers, while keeping 5V logic power to the Arduino Mega and Raspberry Pi intact so telemetry and diagnostics remain visible during an emergency trip.

Motor Driver Interface Analysis (setMotor() Verification)

The existing setMotor() function drives 1 PWM pin + 2 Direction pins (inA, inB) per channel:

CommandPWM PinIN1 (inA)IN2 (inB)Bridge Behavior
Stop (0)0LOWLOWBridge Disabled (Coast)
Forward (+spd)spd (1–255)HIGHLOWForward Drive
Reverse (-spd)spd (1–255)LOWHIGHReverse Drive

Driver Compatibility Note: Directly compatible with L298N (ENA=PWM, IN1/IN2=Dir), TB6612FNG, or VNH2SP30. Standard BTS7960 (IBT-2) modules use dual PWM inputs (RPWM/LPWM) + R_EN/L_EN and are not drop-in compatible with 1-PWM + 2-Dir pin mapping unless R_EN+L_EN are tied to the PWM pin and RPWM/LPWM to IN1/IN2. Furthermore, driving 4 parallel 12V actuators on a single L298N channel (~2A max) can overload the bridge under stall load — verify driver current capacity first!
